# Merchant Recommendation System

Built a merchant recommendation system to predict the top 10 merchants for each customer using transaction and behavioral data. Developed an ETL pipeline with KNN-based imputation, outlier handling, categorical encoding, and class balancing via SMOTETomek. Trained and compared LightGBM and CatBoost models, achieving 88.51% accuracy and generating personalized merchant recommendations at scale.
